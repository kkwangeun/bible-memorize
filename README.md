# bible-memorize
"로마서 8장 1-11절 암송 도우미 (게임형 웹앱)" — 선택
📖 Bible Memorize
성경 본문 암송을 도와주는 게임형 웹앱입니다. 현재 로마서 8장 1-11절 지원.
🔗 사용하기: 여기 클릭 — 또는 GitHub Pages URL 접속

✨ 주요 기능
🏆 스테이지 게임 방식

11개 스테이지 + 최종 보스
한 스테이지 클리어해야 다음 스테이지가 잠금 해제
별 ⭐ 시스템으로 진행률 시각화

🎯 5단계 미션 (한 절당)

📖 익히기 — 본문 5회 소리내어 읽기
👁 첫글자 외우기 — 첫글자만 보고 3회 떠올리기
✏️ 빈칸 채우기 — 60% 빈칸 모두 정확히 채우기 (100% 정답 필요)
🎤 음성 암송 — 마이크에 대고 외운 대로 말하기 (한 어절도 빠뜨림 없이)
⚡ 누적 암송 — 이전 절 + 이번 절 모두 정확히 연속 암송

👑 최종 보스

1절부터 11절까지 끊지 않고 연속 암송
통과 시 황금 인증서 발급

🔓 자유 학습 모드

첫 스테이지 클리어 후 해제
전체보기 / 첫글자 / 빈칸 / 음성 테스트
해제된 절만 표시


🛠 기술적 특징

HTML 단일 파일 — 별도 빌드/배포 도구 불필요
데이터는 브라우저 로컬 저장소 (localStorage) — 외부 서버 없이 동작
Web Speech API — Chrome / Safari에서 음성 인식
다크 테마 + 반응형 디자인 (모바일 최적화)
PWA 메타태그 — 홈 화면 추가 시 앱처럼 동작
편집 거리(Levenshtein) 알고리즘 — 한국어 음성 인식 오차 흡수


📱 모바일에서 앱처럼 사용하기

iPhone Safari에서 사이트 접속
공유 버튼 클릭
"홈 화면에 추가" 선택
홈 화면 아이콘 탭하면 전체화면 앱으로 실행됨


⚠️ 주의사항

음성 인식은 인터넷 연결 필요 (Google/Apple 서버 사용)
한국어 음성 인식은 100% 정확하지 않으므로, 발음이 유사한 단어는 유사도 70% 이상이면 통과 처리
본문은 개역개정 번역 사용
